## 🚀 Running Examples

Each item is structured as a self-contained, standalone Node.js environment layer. You can run any individual lab or workshop file from your terminal root using the native node engine execution pattern:

```bash
node boolean-and-numbers/labs/lab-boolean-basics.js
```
