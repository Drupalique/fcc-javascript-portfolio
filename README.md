# freeCodeCamp JavaScript Portfolio

Example exercises organized by topic, modeled after the labs and workshops format used in freeCodeCamp's JavaScript curriculum.

## 📂 Repository Structure

Each topic folder contains dedicated subdirectories designed to separate isolated concept practice from integrated application:
- **`labs/`**: Short, focused exercises practicing a single target concept.
- **`workshops/`**: Slightly larger exercises combining several concepts into mini-projects.

---

## 🛠️ Topics & Core Concepts

Click on a topic below to expand its core concepts, practice goals, and folder breakdowns.

<details>
<summary><b>1. variables-and-strings</b></summary>

### Core Concepts
*   **Variable Declarations & Scope:** Master block-scoped `let`, immutable `const`, and legacy function-scoped `var`.
*   **String Manipulation:** Utilize template literals for clean interpolation, character indexing, and basic string evaluation.
*   **Built-in Methods:** Leverage fundamental tools like `.length`, `.indexOf()`, and `.slice()`.

### Directory Layout
*   `variables-and-strings/labs/` — Targeted micro-exercises on strings and declarations.
*   `variables-and-strings/workshops/` — Combined script pipelines formatting text block payloads.
</details>

<details>
<summary><b>2. boolean-and-numbers</b></summary>

### Core Concepts
*   **Logical & Comparison Operators:** Evaluate expressions using loose (`==`) vs. strict (`===`) inequality, conjunctions (`&&`), and disjunctions (`||`).
*   **Control Flow Foundations:** Build predictable conditional paths parsing truthy and falsy rules.
*   **Arithmetic & Numeric Utilities:** Compute calculations confidently using standard operators and the native `Math` global object.

### Directory Layout
*   `boolean-and-numbers/labs/` — Snippets exploring binary states, evaluations, and mathematical formulas.
*   `boolean-and-numbers/workshops/` — Functional evaluation algorithms processing structured calculations.
</details>

<details>
<summary><b>3. objects</b></summary>

### Core Concepts
*   **Literal Instantiation:** Create structural data payloads cleanly with custom object keys.
*   **Property Mutation & Retrieval:** Toggle safely between flexible bracket notation (`obj[key]`) and standard dot notation (`obj.key`).
*   **Complex Collections:** Manipulate deeply nested properties, construct objects featuring encapsulated methods, and extract properties using structural destructuring.

### Directory Layout
*   `objects/labs/` — Concise challenges initializing properties and invoking encapsulated object actions.
*   `objects/workshops/` — Mock datasets mimicking real-world payloads, API responses, and multi-layered configurations.
</details>

## 🚀 Running Examples

Every single file inside the subdirectories functions as an isolated, executable standalone environment. You can instantly run any laboratory script locally using your system's Node.js runtime framework:

```bash
node boolean-and-numbers/labs/lab-boolean-basics.js
```
